ALESIS Discord Bot

Simple Discord interactions for checking context, checking permissions, and preparing public messages with a private confirmation step.

Join our Discord Explore commands →
Quick start Try /context first to see which Discord context your command is running in.

Commands

ALESIS currently provides four slash commands.

SLASH COMMAND

/custom-message

Prepare a message before sending it publicly. The message will be sent 5 times in the current conversation.

/custom-message message:<message>

How it works

  1. Run /custom-message.
  2. Enter your message.
  3. ALESIS shows a private confirmation embed showing the message and count.
  4. Press Send.
  5. The message is sent 5 times publicly.
Message limit: Discord messages are limited to 2,000 characters.
SLASH COMMAND

/use-template

Use a saved message template. The template will be sent 10 times in the current conversation.

/use-template template:<template_id>

How it works

  1. Run /use-template.
  2. Choose a template from the dropdown.
  3. ALESIS shows a private confirmation embed showing the template and count.
  4. Press Send.
  5. The template is sent 10 times publicly.

Available Templates

  1. Template 1: Discord bot invitation message
  2. Template 2: Community welcome message
Note: Templates are pre-configured by the bot administrator and cannot be edited by users.
SLASH COMMAND

/context

Displays the current Discord context.

/context

Server

Shows the server name and current channel.

Direct Message

Identifies the conversation as a direct message.

Group DM

Identifies the conversation as a group DM and displays the channel ID.

SLASH COMMAND

/permcheck

Checks the bot's permissions in the current server channel.

/permcheck
Send Messages Checks whether the bot can send messages.
Embed Links Checks whether the bot can send embeds.
Mention Everyone Checks whether @everyone and @here mentions are allowed.

In DMs and group DMs, server permissions do not apply.

Installation

Install the Discord application using the OAuth2 installation link configured for your Discord application.

1
Open the installation link Open your bot's Discord installation URL.
2
Select a server Choose the server where you want to install the bot.
3
Review permissions Review the permissions Discord requests.
4
Start using ALESIS Run /context to test the installation.

Permissions

ALESIS checks the bot's permissions dynamically when /permcheck is used. In server channels, the bot checks: Send Messages, Embed Links, and Mention Everyone.

Errors

Permission Denied Discord did not allow the application to send the public message.
Message Too Long The message is longer than Discord's 2,000-character limit.
Command Error An application command encountered an unexpected error. Check the bot console for details.
